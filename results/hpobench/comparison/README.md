# Deprecated exploratory comparisons

The CSV files in this directory are retained only as historical exploratory
artifacts. Their before/after labels are not encoded in the current raw
trajectory archive, so the deltas cannot be reconstructed independently and
are not used by the paper, README, figure generator, or reported statistics.

Publication results are generated from `../results_merged_labeled.csv` and
`../statistics_auc/`. Dataset-label recovery provenance and validation checks
are recorded in `../dataset_label_recovery.json`.
